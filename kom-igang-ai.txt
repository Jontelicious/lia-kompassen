Huvudmallen är enkel HTML/CSS/JavaScript på GitHub. Förklara skillnaden mellan att testa en webbversion, Use this template för ett nytt repo, git clone för en lokal kopia, GitHub Download ZIP och Lovable Remix. Exportera före import, adressbyte eller koduppdatering. Lagring per sökväg undviker kollisioner men ger inga privata konton. Rensa aldrig webbläsardata som första felsökningsåtgärd.
